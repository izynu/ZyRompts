Overview/Privacy

Privacy policy

This page covers two things that are often confused: the website you are reading, and the software you install. They behave differently, and both are described here.

Last updated 13 November 2026.

The short version

The website sets no cookies, runs no analytics, and loads no third-party scripts. The software makes no network requests of its own. Neither one has a server that receives your data, because neither one has a server at all.

This website

What is collected

Nothing. The site is static files served by GitHub Pages. It contains no analytics, no tracking pixels, no advertising, no social widgets and no third-party scripts. Fonts are served from this site, not from a font CDN, so your browser makes no request to a third party to render a page here.

Hosting

The site is hosted on GitHub Pages. GitHub receives standard web server data when it serves any page, including IP addresses, browser user agent strings and request timestamps, and it may set its own cookies at the github.io domain. That processing is described in the GitHub Privacy Statement and is outside this project's control.

Storage in your browser

The site stores one preference in your browser's local storage: the theme you pick if you use the theme control. Its key is zyrompts-theme and its value is either light or dark. It never leaves your browser, it is never sent to anyone, and you can delete it by clearing site data. If storage is unavailable, which happens in some private browsing modes, the site simply follows your system theme.

Links to other sites

Pages here link to GitHub. Following a link takes you to a site governed by its own privacy policy. This site does not embed content from other sites and does not use link-tracking redirects.

The software

No network calls

The Python package in core/ has no third-party dependencies and makes no outbound network requests. It reads and writes files in the directory you run it in. It does not contact the maintainers and contains no telemetry endpoint.

What it writes to disk

  • .zyrompts/state/project.json and .zyrompts/state/events.jsonl, holding workflow state and an event log for the project you run it against.
  • Telemetry records for cost and duration, stored locally in the same project directory. Nothing is transmitted anywhere.

Both are plain files you can read, edit or delete. Removing the .zyrompts directory resets the project state.

Credentials in your input

If you pass text containing a credential to a command such as zyrompts redact, the tool replaces the credential with a placeholder and reports only the kind of credential it found. The original value is not written to the state files by that command.

This is a safety feature, not a guarantee. Do not pass credentials to any tool, this one included, unless you have decided that is acceptable.

When you use it inside an AI agent

ZyRompts runs before and around a coding agent, but the agent itself is separate software with its own data handling. When you wire the hook dispatcher into Claude Code or another tool, the conversation, the file contents the agent reads and the tool output it receives are handled under that product's terms and privacy policy, not this one. Read the policy of the agent you are running.

Children

This project is developer tooling. It is not directed at children and collects no personal information from anyone.

Changes to this policy

If this policy changes, the date at the top of the page changes and the edit appears in the repository history at site/privacy.html. Because the project is open source, every version of this page remains readable in that history.

Contact

Questions about this policy go to the issue tracker. For a security concern, follow the reporting process instead of opening a public issue.
